## 📲 دانلود و نصب روی گوشی اندروید
برای نصب مستقیم روی گوشی اندروید خود:
1. فایل **[zarbolmasal.apk](https://raw.githubusercontent.com/Mehrafit/zarbolmasal-apk/main/zarbolmasal.apk)** را از لینک بالا دانلود کنید.
2. در گوشی خود گزینه **Install from Unknown Sources** (نصب از منابع ناشناس) را تایید کنید.
3. بازی را اجرا کرده و لذت ببرید!

## ✨ ویژگی‌های برجسته بازی

- **دموی ۲ ثانیه‌ای آغازین**: انیمیشن سنتی همراه با آوای زنگ که با کلیک روی شروع بازی پخش شده و وارد منوی اصلی می‌شود.
- **۱۰۰ مرحله اصیل ضرب‌المثل**:
  - باز شدن مرحله به مرحله (هر مرحله تا زمان رد نشدن قبلی قفل است).
  - منوی نمایش تمامی ۱۰۰ مرحله با فیلتر بازشده، تکمیل‌شده و ستاره‌ها.
  - توضیحات کامل پیرامون ریشه و معنی هر ضرب‌المثل پس از حدس درست.
- **تایمر ۵۰ ثانیه‌ای و بونوس سرعت**:
  - اگر معما در کمتر از ۲۰ ثانیه اول حل شود، بونوس سرعت (+۲۰ سکه اضافه) داده می‌شود.
- **سیستم جان و قلب**: کسر یک جان به ازای هر پاسخ اشتباه با قابلیت احیا و دریافت سکه با تماشای تبلیغ ۵ ثانیه‌ای.
- **کیبورد فارسی درون بازی**: شامل حروف درهم‌ریخته اختصاصی هر مرحله، کلید فاصله و نیم‌فاصله.
- **فروشگاه سکه‌ای تم‌ها و پوسته‌ها**:
  - تم‌های فصول چهارگانه: پاییز طلایی، بهار شکوفه‌ها، تابستان آفتابی، زمستان سپید دماوند.
  - تم‌های شهرهای ایران: اصفهان فیروزه‌ای، شیراز بهارنارنج، تخت جمشید باستان، یزد کهن و بادگیرها.
- **بازگشایی دسته‌های جدید با سکه**:
  - **ضرب‌المثل‌های ایرانی**: رایگان و باز از ابتدا (۱۰۰ مرحله).
  - **اسطوره‌ها و دانستنی‌های فوتبال**: بازگشایی با ۵۰۰ سکه.
  - **سینما و فیلم‌های ماندگار ایرانی**: بازگشایی با ۱۰۰۰ سکه.
- **کاملاً آفلاین**: تمام داده‌ها و خریدهای سکه‌ای در حافظه دستگاه ذخیره می‌شوند و نیاز به اینترنت ندارد.

- **فریمورک**: React 19 + TypeScript + Vite + Tailwind CSS v4
- **موتور صوتی**: Web Audio API Procedural Synthesizer
- **پلتفرم موبایل**: Android Capacitor Native Wrapper (SDK 24+)
- **فایل خروجی**: `zarbolmasal.apk` امضا شده با کلید استاندارد اندروید
